Fügen Sie den Installationscode in den `<head>` **jeder Seite** ein, vor jedem anderen Skript, das Cookies setzt. Der Banner muss zuerst laden, damit er andere Cookies zurückhalten kann, bis die Besucher entschieden haben.

## Was der Code enthält

- Die **Banner-Konfiguration** für Ihre Domain und das **Banner-Skript**.
- Wenn Analytics für die Domain aktiv ist: den **Analytics-Tracker** mit Ihrem Site-Key (`data-site="…"`).

Der Tracker liest die Entscheidung der Besucher aus dem Banner – eine zweite Einwilligungslösung ist nicht nötig.

## Wo Sie ihn finden

- **Loslegen → Auf Ihrer Website installieren** – Domain wählen; ist Analytics aus, fügt **Analytics einschalten** den Tracker zum Code hinzu.
- **Domain hinzufügen** – nach dem Speichern **Analytics auch installieren** ankreuzen, um sofort den kombinierten Code zu erhalten.
- **Einstellungen → Analytics-Skript** – nur die Tracker-Zeile, für Websites, die den Banner schon haben.

> Code geändert? Es kann ein paar Minuten dauern, bis die erste Einwilligung oder der erste Besuch erscheint und der passende Schritt in Loslegen abgehakt wird.
