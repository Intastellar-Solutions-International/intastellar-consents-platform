**Loslegen** führt Sie in einer Liste von einem neuen Konto zu einer funktionierenden Einrichtung. Jeder Schritt hakt sich selbst ab, sobald Ihre eigenen Daten zeigen, dass er erledigt ist – Sie können keinen versehentlich überspringen.

## Die Schritte

1. **Domain hinzufügen** – gilt für beide Produkte.
2. **Auf Ihrer Website installieren** – ein Code für den Banner und, sobald aktiviert, Analytics. Siehe [Code installieren](help:install-code).
3. **Einwilligung:** auf die erste erfasste Einwilligung warten, bestätigen, dass Ihnen die Domain gehört, einen ersten Cookie-Scan durchführen und einen ersten Bericht erstellen.
4. **Analytics:** für Ihre Domain einschalten (ein Klick – das erzeugt den Site-Key) und auf den ersten Besuch warten.

Eine Werbeplattform zu verbinden und eine Conversion festzulegen ist **optional** – das liefert Werbeausgaben und Conversions, die Einrichtung gilt aber auch ohne als abgeschlossen.

> Bis die Einrichtung abgeschlossen ist, zeigen beide Startseiten eine kleine **Einrichtung**-Karte mit Ihrem Fortschritt und dem nächsten Schritt.
